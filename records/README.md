# Records

One YAML file per federation connection problem. Group records by
topic in a folder, for example `state-identifiers/`.

A record is a draft until a reviewer accepts it. Its `status`
says where it stands: `open`, `under_review`, `accepted`, or
`rejected`.

Do not invent a value. If a namespace, an example identifier, or a
count is not verified yet, write `to_be_confirmed` and add a note
saying what still needs checking.
